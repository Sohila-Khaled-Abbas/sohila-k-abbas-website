# LinkedIn website showcase

The showcase presents the published website, its project collection, and actual dashboard/report views. It uses the same portrait palette and short on-screen descriptions so the story can be followed without sound.

Suggested sequence:

1. Portrait-led home and professional positioning.
2. Project gallery and tool-based discovery.
3. PixelFed architecture and project context.
4. Interactive Power BI collection.
5. A working public report.
6. Automation workflow and source documentation.
7. Name, role, website address, and an invitation to explore.

Use actual published screens. Keep project counts tied to the current content snapshot and describe source previews as source previews. Do not turn synthetic report metrics into claims about client impact.

The delivery format is an MP4 with H.264 video, 1080 × 1350 pixels, 30fps, and readable on-screen text. Capture and export after the corresponding production deployment is ready. Keep the large rendered video outside Git history; the website source and documentation remain in this repository.

For a LinkedIn post, upload the MP4 as a native video and include the website link in the accompanying post text. Review the preview before posting. Creating the video does not post it automatically.
