# Architecture

The public portfolio is generated as static HTML with Node.js 22 or later. An isolated Vercel Node.js endpoint authorizes and validates approval-only business inquiries. Its phone validation uses the pinned `libphonenumber-js` dependency. No database, email delivery provider, or SMS provider is required.

## Source responsibilities

| Location | Responsibility |
| --- | --- |
| `content/profile.json` | Identity, headline, experience, skills, education, and dated training |
| `content/repositories.json` | Snapshot of public repositories and fork attribution |
| `content/project-details.json` | Original-project titles, technical context, public files, workflow overviews, and media |
| `content/project-previews.json` | Report screenshots, Power BI URLs, available files, and presentations |
| `content/project-status.json` | Explicitly maintained in-progress labels |
| `content/community.json`, `content/credentials.json` | Community roles and learning collection |
| `scripts/build.mjs` | Loads data, assembles HTML, creates metadata and sitemap, and copies assets |
| `scripts/pages.mjs` | Profile, experience, learning, contact, and case-study templates |
| `scripts/previews.mjs` | Dashboard collection, report pages, embeds, and screenshot dialog markup |
| `scripts/studio.mjs` | Portrait-led home, repository previews, community, credentials, services, and search |
| `src/assets/theme.css` | Shared light/dark color tokens and theme-specific overrides |
| `src/assets/*.js` | Progressive enhancement for filters, search, dialogs, preferences, and the email draft |
| `dist/` | Generated hosting output; not committed |
| `api/business-inquiry.mjs`, `server/` | Private-invitation authorization, encrypted approvals, and server validation |
| `scripts/business-access.mjs` | Owner-operated approval and revocation commands |

`src/home.html` supplies the shared icon symbols and the illustrative data-process example. The current home composition is generated by `studioHome()` in `scripts/studio.mjs`; editing the old hero markup alone does not change the current home.

## Build flow

Run `npm run build` from the site directory. The generator reads JSON content, renders every route, copies the static assets, and writes `site-manifest.json`, `robots.txt`, and the canonical sitemap. `npm run check` validates the output's local links, anchors, page structure, repository coverage, report sources, and hosting configuration.

Vercel builds `portfolio-site/` from the repository's `main` branch. The same `dist/` output can be deployed to Firebase Hosting. The legacy React/Vite app at the GitHub repository root is separate from this build.

## Visitor data flow

The main content, project links, and file links are rendered in HTML. JavaScript adds filtering, keyboard search, screenshot navigation, and display preferences. Theme and motion choices use local storage. Search/filter state uses URL parameters.

A Power BI iframe is created only after the visitor clicks **Load interactive report**. Business inquiries require a private invitation issued after human verification of registration, domain, and work-email ownership. The server checks authorization and input rules, then returns a `mailto:` draft for review; it does not store submissions or send email automatically. Private inputs and invitation files stay outside Git history. See [the business inquiry guide](BUSINESS_INQUIRIES.md). No visitor analytics is included.

## Accuracy boundary

Repository presence demonstrates source availability. It does not establish employment, a client relationship, production deployment, business impact, or a completed certification. Use the provenance guides when adding content and keep synthetic scenarios labeled.
